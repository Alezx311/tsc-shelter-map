# Карта укриттів ТСЦ — стан

Пілот для плаката працівника МВС і онлайн-карти відвідувачів. Код: `~/Work/tsc-shelter-map`; технічні деталі, перевірки та геометрія — у README й журналі даних проєкту.

## Зроблено

- [x] Прочитано всі 12 офіційних схем №3246: наказ 17.12.2025 №260; категорії внесено окремо для кожного маршруту.
- [x] 209 укриттів з трьох офіційних джерел (громада, КОВА, КМДА), включно з підвалами житлових будинків; входи й доступність не підтверджені.
- [x] Оцифровано й звірено зі схемами №1, 2, 4, 5, 7, 11, 12; є контрольні точки та накладання на оригінали. Орієнтовна точність ліній 30–50 м, не смуги руху.
- [x] Вибір маршрутів і категорій, відстань 500 м, підписи, розмір позначок, товщина ліній, режим скриншота.
- [x] Тести географічного фільтра, зокрема середина довгого сегмента та точка на межі.
- [x] Збірка й перевірка настільного/мобільного відображення; скриншоти збережено в проєкті.

## Ще не готово

- [ ] Уточнити порядок відгалужень №3 і №10 за читабельнішими схемами або поясненням ТСЦ. №3 має часткову чернетку.
- [ ] Уточнити геоприв’язку №6, №8, №9: залишкові відхилення контрольних точок до 52–59 м. Ці п’ять маршрутів не відображаються як підтверджені.
- [ ] Знайти опубліковане джерело підвалів ЖК Софіївської Борщагівки (запит до громади щодо книги обліку найпростіших укриттів).
- [ ] Після завершення даних розмістити статичну збірку на погодженому хостингу для відвідувачів. Зараз запуск локальний.

Повний критерій готовності **всіх маршрутів** поки не виконано. Польової перевірки укриттів і маршрутів не було.

## Зафіксовано

Сторонні траси й інші ТСЦ не використовуємо. Київський API, сервер, акаунти та PDF не входять до пілоту. Типово вибрано №4: 10 укриттів у межах 500 м; для №1 — 15.
