# Карта укриттів ТСЦ

Екзаменаційні маршрути та укриття поруч: працівник МВС готує кадр для плаката, відвідувач користується картою онлайн. Пілот — **№3246, Софіївська Борщагівка**.

**Шлях:** `~/Work/tsc-shelter-map`

Робоча карта має 7 звірених маршрутів і 13 точок укриттів з офіційної карти громади. П’ять маршрутів потребують уточнення; входи й доступність укриттів не підтверджені. Публічне розміщення ще не виконане.
