# ТСЦ №3246 · Маршрути та укриття

https://alezx311.github.io/tsc-shelter-map/

Локальна статична вебкарта Софіївської Борщагівки: React, TypeScript, Vite, Leaflet. Сервер застосунку, облікові записи й ключі API не потрібні.

## Запуск на локальній машині

```sh
npm ci
npm run dev
```

Відкрити http://127.0.0.1:5173. `npm run build` створює `dist/` для статичного хостингу (HTTPS для публічного доступу). `npm run preview` перевіряє збірку локально. Дані входять у збірку; інтернет потрібний для тайлів OSM. На телефоні потрібен доступний йому хостинг — localhost комп’ютера не є адресою телефона.

## Стан даних — 15.09.2026

- Прочитано всі **12 офіційних схем**, наказ **17.12.2025 №260**. Оригінали надав користувач у `research/HSC 3246/` після HTTP 403 під час прямого завантаження.
- **7 маршрутів** доступні на карті: **1, 2, 4, 5, 7, 11, 12**. Послідовності ліній вручну звірені з синіми лініями й червоними стрілками схем; повтори та розвороти збережені.
- **3, 6, 8, 9, 10 — не готові.** №3 і №10 мають неоднозначний порядок відгалужень; №6, №8, №9 — недостатньо точну геоприв’язку (залишкові відхилення до 52–59 м). Чернетки з `verified: false` не відображаються і не беруть участі у фільтрі. Чернетка №3 не охоплює всі гілки.
- **209 укриттів** (16.09.2026) — не лише облаштовані захисні споруди, а й найпростіші укриття: підвали багатоквартирних будинків, паркінги, підземні переходи. Координати всіх об’єктів перенесено без змін:
  - **13** — [перелік](https://brada.gov.ua/dsns/skhovyshcha-ukryttia-hromady/) і [карта](https://brada.gov.ua/maps/shelters.html) Борщагівської громади. Ті самі 13 об’єктів є на карті КОВА — звідти додано тип і графік, дублікатів немає.
  - **69** — [мапа укриттів Київської ОВА](https://koda.gov.ua/czyvilnyj-front/zahysni-sporudy-tochky-obigrivu/ukryttya/) (Google My Maps, KML): решта об’єктів Борщагівської громади, Вишневе (переважно підвали житлових будинків), Крюківщина, Святопетрівське, Княжичі.
  - **127** — [мапа укриттів КМДА](https://gis.kyivcity.gov.ua/shelter/) (шар `KYIV_API/Public_protection`, лише `actual=1`): Святошинський район Києва біля Кільцевої дороги.
  - Об’єкти КОВА/КМДА беруться в межах **2 км** від будь-якої з 12 ліній схем (включно з неперевіреними); Борщагівська громада — повністю. Для відстані понад 2 км інтерфейс попереджає про неповний результат.
  - **Прогалина:** підвали ЖК у самій Софіївській Борщагівці (Софія Резіденс, Софіївська Слобідка тощо) не опубліковані жодним офіційним джерелом — громада веде «книгу обліку найпростіших укриттів», але не оприлюднює її. OSM для цього району містить лише історичні ДОТи. Ці укриття на карті відсутні, доки не з’явиться джерело.
  - Входи, місткість і поточна доступність не підтверджені; графік і доступність для маломобільних — лише як їх вказує джерело.
- `scheme-checked` означає звірку з растровою схемою, **не польову перевірку**. Орієнтовна точність ліній — 30–50 м, не смуги руху. Невеликі залишкові похибки опорних точок самі по собі не доводять точність усієї лінії.

Отже, повний критерій готовності всіх маршрутів пілоту ще не виконаний. Географічний фільтр точний відносно збережених ліній; об’єкт поблизу межі коридору може змінити належність після уточнення геометрії.

## Керування

Виберіть категорію, один/кілька/всі перевірені маршрути й відстань (типово 500 м). Фільтр обчислює найкоротшу сферичну відстань до кожного сегмента, включно з його серединою, не пішохідний маршрут. Типово вибрано №4: 10 укриттів у межах 500 м. Для №1 — 15. Позначки: зелені — найпростіші укриття, сині — захисні споруди (ПРУ, подвійного призначення).

Підписи, товщина ліній і розмір позначок змінюються в панелі. **H** або кнопка приховує панель без зміни розміру карти, масштабу й центру. Повернення — **H** чи торкання карти. Легенда, дата даних, масштаб і атрибуція залишаються. «Умістити вибране» змінює кадр лише за явним запитом. PDF-експорту немає.

## Аудит та оновлення

- `public/data/routes.geojson`, `shelters.geojson` — робочі дані.
- `public/data/verification.json` — джерела, статуси, SHA-256 оригіналів, контрольні точки та залишкові похибки.
- `research/shelters-source.html`, `shelters-koda.kml`, `shelters-kyiv.geojson` — збережені відповіді джерел укриттів. Оновлення: завантажити KML `https://www.google.com/maps/d/kml?mid=133eWWMRjEzUA1_n5d2Ae28nwvrIP41U&forcekml=1` і запит шару КМДА (bbox 30.27,50.33–30.46,50.46, `f=geojson`), потім `python3 scripts/build-data.py`. Відповідність записів КОВА об’єктам громади задана явно (`koda_to_brada`) і перевіряється під час збирання.
- `research/traces.json` — ручні піксельні послідовності та відповідні координати опорних точок; це актуальне джерело оцифрування.
- `research/qa-*.png` — діагностичні накладання: оригінал, зелена геометрія OSM, рожева послідовність маршруту, жовті опорні точки.
- `research/osm-*.xml` — збережені відповіді OSM API для геоприв’язки; OSM contributors, ODbL. Це не офіційні екзаменаційні маршрути.
- `public/schemes/` — копії офіційних JPG для локального перегляду.

Повторне складання після редагування опорних точок/послідовностей:

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/georeference.py
python3 scripts/build-data.py
```

До зміни `verified` необхідно прочитати заголовок, зіставити **весь** маршрут із оригіналом, звірити порядок кожного проїзду й перевірити геоприв’язку. Не з’єднувати неоднозначні гілки припущенням. Старі допоміжні `add-traces.py`/`more-traces.py` не запускати: вони були одноразовими чернетками й не є джерелом актуальних виправлень.

## Перевірки

```sh
npm test
npm run build
npm run test:e2e
```

E2E використовує `/usr/bin/chromium` і локальний Vite; шлях до Chromium можна змінити у `playwright.config.ts`. Перевіряються фільтри, порожня вибірка, категорії, приховування без зміни кадру, мобільне повернення, явні помилки даних і тайлів. Скриншоти — `research/screenshots/`.

## Картографічна основа

Стандартні тайли `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, видима атрибуція й звичайний браузерний кеш. Без попереднього масового завантаження, offline cache та service worker. Перед суттєвим зростанням навантаження обрати відповідного провайдера відповідно до [політики OSM](https://operations.osmfoundation.org/policies/tiles/). Екзаменаційні схеми — ГСЦ МВС; сторінка громади вказує CC BY 4.0. Для макетів зберігайте атрибуцію.

Пілот стосується лише №3246. Інші ТСЦ, сторонні траси, акаунти та PDF — поза поточною реалізацією. Дані КМДА використані як збережений знімок біля маршрутів, без живих запитів з браузера. Київ і область — наступний етап.
